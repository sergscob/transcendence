# 42 transcendence

## Description

Backend - Django, frontend - React

## Installation 

#### Back :

```bash
cd back
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
```

#### Front:

```bash
cd front
npm install
```


## Run

#### Back:


```bash
cd back
source venv/bin/activate
python manage.py runserver
```
or 
```bash
make back
```

#### Front:

```bash
cd front
npm run dev
```
or 
```bash
make front
```
